# CareRent Frontend

A presentation-ready React + Vite frontend prototype for the CareRent hospital-connected medical equipment rental concept.

## Run
1. Open this folder in PowerShell.
2. Run `npm install`
3. Run `npm run dev`
4. Open the Local URL shown by Vite.

This is a frontend demo. Authentication is stored in browser localStorage for presentation purposes; a real deployment should use a secure backend/authentication service.
